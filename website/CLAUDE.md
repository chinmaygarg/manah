# Manah Group Website — Claude guide

Next.js 16 + React 19 + Tailwind CSS v4 corporate marketing site.

## Commands

- `npm run dev` — dev server (Turbopack, http://localhost:3000)
- `npm run build` — production build (runs `prebuild` → `gen:blur` first)
- `npm run gen:blur` — regenerate image blur placeholders
- `npm run lint` — ESLint

## Images & blur placeholders

Content photos render via `<BlurImage>` (`src/components/ui/BlurImage.tsx`),
a wrapper over `next/image` that supplies a real low-quality blurred preview
(LQIP) as the loading placeholder — so images fade in from a soft blur of
their own colours instead of a flat box.

LQIPs live in `src/lib/blur-map.ts`, generated by `scripts/generate-blur.mjs`
from everything in `public/images/` (logos excluded). **This file is
AUTO-GENERATED — do not edit it by hand.**

**After adding or replacing any image in `public/images/`, run
`npm run gen:blur`** so its placeholder exists. `npm run build` does this
automatically via the `prebuild` script, but run it manually during `dev`.
Commit the updated `src/lib/blur-map.ts`.

Use `<BlurImage>` (not raw `next/image`) for content photos. Logos and icons
can stay as plain `<Image>` — they don't need a blur placeholder.
